# ISO 27001:2022 Control Mapping for Kubernetes
# Requirements: 9.3, 9.4, 9.5

This document maps ISO 27001:2022 Annex A controls to CIS Kubernetes Benchmark controls
and SecOps implementation components. Use this for demonstrating ISO 27001 compliance
coverage to auditors.

> **Note:** ISO 27001:2022 updated Annex A from 114 controls (2013 edition) to 93 controls
> organized into 4 themes. This mapping uses the 2022 edition.

## Annex A Control Themes

| Theme | Controls | Description |
|-------|----------|-------------|
| 5. Organizational Controls | 5.1–5.37 | Policies, roles, responsibilities |
| 6. People Controls | 6.1–6.8 | HR security, training |
| 7. Physical Controls | 7.1–7.14 | Physical security |
| 8. Technological Controls | 8.1–8.34 | Technical security measures |

## Audit Evidence Collection

For ISO 27001 internal/external audits, collect the following evidence:

```bash
# CIS Benchmark scan results (8.8, 8.9)
kubectl get configmap -n secops -l scan-type=cis-benchmark -o json > cis-results.json

# Kyverno policy violations (5.36)
kubectl get policyreport -A -o json > policy-violations.json

# RBAC configuration (5.2)
kubectl get clusterrolebindings,rolebindings -A -o json > rbac.json

# Network policies (8.22)
kubectl get networkpolicies -A -o json > network-policies.json

# Falco alert history (Grafana LogQL)
# {source="k8s-audit"} | json | line_format "{{.user_username}} {{.verb}} {{.resource}} {{.namespace}}"
```
